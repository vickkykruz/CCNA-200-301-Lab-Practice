# Lab 1 -- Build and Identify Network Devices (Day 1)

**Topology to build**:
2 PCs → Switch → Router → another Switch → Server

**Devices to place**:
→ 2960 switch (x2)
→ 2911 router (x1)
→ PC (x2)
→ Server (x1)

## Tasks

1. Open Packet Tracer → drag and drop the devices above
2. Label each device correctly:
   PC1, PC2, SW1, R1, SW2, Server1

3. Connect them using the CORRECT cable type:
   PC1  → SW1  (which cable type?)
   PC2  → SW1  (which cable type?)
   SW1  → R1   (which cable type?)
   R1   → SW2  (which cable type?)
   SW2  → Server1 (which cable type?)

4. Answer before connecting:
   → PC to Switch = straight-through or crossover?
   → Switch to Router = straight-through or crossover?
