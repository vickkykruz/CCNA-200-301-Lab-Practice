# Lab 4 -- Combining All Three Days (Challenge Lab)

**Objective**: Build, cable, address and verify a complete small network with no instructions -- just the requirements.

```
Requirements (you figure out how):

Devices:
→ 3 PCs (PC1, PC2, PC3)
→ 1 switch (SW1)
→ 1 router (R1)
→ 1 server (Server1)

Addressing:
→ PC1: 192.168.10.10/24  GW: 192.168.10.1
→ PC2: 192.168.10.11/24  GW: 192.168.10.1
→ PC3: 192.168.10.12/24  GW: 192.168.10.1
→ Server1: 192.168.10.100/24  GW: 192.168.10.1
→ R1 interface: 192.168.10.1/24

Requirements:
1. Use correct cable types throughout
2. All links must show green
3. All PCs must ping the router ✅
4. All PCs must ping each other ✅
5. All PCs must ping the server ✅

Verification commands to run on R1:
→ show interfaces
→ show ip interface brief
→ show version  ← tells you IOS version and device info
```
